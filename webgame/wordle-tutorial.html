Criando um Wordle com React

Neste tutorial você vai construir um clone funcional do Wordle — o famoso jogo de adivinhar palavras — usando React do zero. Ao final, você terá um jogo completo com tabuleiro, teclado virtual e feedback visual de letras corretas.

🎮

O que você vai construir

  • Uma grade 6×5 de tiles que mostram seus chutes
  • Feedback visual: 🟩 certo, 🟨 presente, ⬛ ausente
  • Teclado virtual clicável com estado das letras
  • Suporte a digitação física + animações
  • Detecção de vitória e derrota

Configuração do Projeto

Vamos usar o Vite para criar um projeto React rapidamente. Abra seu terminal e rode:

cd wordle-clone
npm install

Projetando o Estado do Jogo

Antes de escrever qualquer JSX, pense: quais dados o jogo precisa?

EstadoTipoDescrição
secretstringA palavra secreta (ex: "CRANE")
guessesstring[]Chutes já enviados
currentstringO chute sendo digitado agora
gameOverbooleanSe o jogo terminou

Vamos definir também as constantes do jogo:

src/App.jsx// Lista de palavras possíveis (adicione quantas quiser)
const WORDS = [
  "APPLE", "BRAVE", "CRANE", "DRIVE", "EAGLE",
  "FLAME", "GRACE", "HOUSE", "IVORY", "JOKER",
  // ... mais palavras
];

const WORD_LENGTH = 5;   // letras por palavra
const MAX_GUESSES = 6;  // máximo de tentativas

Agora o componente principal com o estado:

import { useState, useEffect, useCallback } from "react";

export default function WordleGame() {
  // Escolhe uma palavra aleatória ao iniciar
  const [secret] = useState(() =>
    WORDS[Math.floor(Math.random() * WORDS.length)]
  );

  const [guesses, setGuesses] = useState([]); // chutes enviados
  const [current, setCurrent] = useState("");   // chute atual
  const [gameOver, setGameOver] = useState(false);

  return <div>{secret}</div>; // temporário
}
💡 Por que useState(() => ...) com função? Passar uma função de inicialização para useState garante que o código rode apenas uma vez — na criação do componente — e não a cada re-render. É a forma correta de inicializar valores aleatórios ou computados.

Construindo o Tabuleiro

O tabuleiro é uma grade de 6 linhas × 5 colunas. Cada célula (tile) mostra uma letra e muda de cor conforme o estado.

Construindo as linhas

Combinamos os chutes enviados + o chute atual + linhas vazias para sempre ter exatamente 6 linhas:

// Monta sempre 6 linhas
const rows = [
  ...guesses,           // chutes já confirmados
  current,              // linha sendo digitada
  ...Array(MAX_GUESSES - guesses.length - 1).fill("") // vazias
].slice(0, MAX_GUESSES);

Renderizando os tiles

return (
  <div className="board">
    {rows.map((guess, rowIdx) => (
      <div key={rowIdx} className="row">
        {Array.from({ length: WORD_LENGTH }, (_, colIdx) => {
          const letter = guess[colIdx] || "";
          const isSubmitted = rowIdx < guesses.length;
          const state = isSubmitted
            ? getTileState(guess, colIdx, secret)
            : letter ? "tbd" : "empty";

          return (
            <div key={colIdx} className={`tile tile-${state}`}>
              {letter}
            </div>
          );
        })}
      </div>
    ))}
  </div>
);

Lógica das Cores

Esta é a parte mais importante do Wordle. Para cada letra de um chute, precisamos determinar:

EstadoCorSignificado
"correct"Verde 🟩Letra certa, posição certa
"present"Amarelo 🟨Letra certa, posição errada
"absent"Cinza ⬛Letra não está na palavra
 
// Retorna o estado de UMA letra em uma posição
function getTileState(guess, index, secret) {
  const letter = guess[index];
  if (!letter) return "empty";
  if (secret[index] === letter) return "correct";  // ✅ posição exata
  if (secret.includes(letter)) return "present"; // 🔄 está na palavra
  return "absent";                               // ❌ não existe
}
📌 Simplificação Esta implementação é uma versão simplificada. O Wordle original tem uma lógica mais sofisticada para lidar com letras duplicadas (ex: se a palavra é "ABBEY" e você chuta "ADDED", apenas um dos "D" fica amarelo). Para este tutorial, mantemos a lógica simples.

Teclado Virtual e Input

O jogo precisa aceitar entrada de duas formas: teclado físico e cliques no teclado virtual.

Capturando o teclado físico

useEffect(() => {
  const handler = (e) => handleKey(e.key.toUpperCase());
  window.addEventListener("keydown", handler);
  return () => window.removeEventListener("keydown", handler);
}, [handleKey]);

Função handleKey

const handleKey = useCallback((key) => {
  if (gameOver) return;

  if (key === "ENTER") {
    submitGuess();
  } else if (key === "BACKSPACE" || key === "⌫") {
    setCurrent(prev => prev.slice(0, -1)); // remove última letra
  } else if (/^[A-Z]$/.test(key) && current.length < WORD_LENGTH) {
    setCurrent(prev => prev + key); // adiciona letra
  }
}, [gameOver, current, submitGuess]);
💡 Por que useCallback? Sem useCallback, a função handleKey seria recriada a cada render. Como ela é usada como dependência no useEffect do listener de teclado, isso causaria o listener ser removido e adicionado novamente a cada tecla pressionada. Com useCallback, a função só muda quando suas dependências mudam.

Renderizando o teclado

const KEYBOARD_ROWS = [
  ["Q","W","E","R","T","Y","U","I","O","P"],
  ["A","S","D","F","G","H","J","K","L"],
  ["ENTER","Z","X","C","V","B","N","M","⌫"],
];

// Descobrir o melhor estado de uma tecla
function getKeyState(letter, guesses, secret) {
  let best = null;
  for (const guess of guesses) {
    for (let i = 0; i < guess.length; i++) {
      if (guess[i] !== letter) continue;
      const state = getTileState(guess, i, secret);
      if (state === "correct") return "correct"; // melhor possível
      if (state === "present") best = "present";
      else if (!best) best = "absent";
    }
  }
  return best;
}

// No JSX:
{KEYBOARD_ROWS.map((row, rIdx) => (
  <div key={rIdx} className="keyboard-row">
    {row.map((key) => (
      <button
        key={key}
        onClick={() => handleKey(key)}
        className={`key key-${getKeyState(key, guesses, secret)}`}
      >
        {key}
      </button>
    ))}
  </div>
))}

Fim de Jogo e Feedback

Enviando um chute

const submitGuess = useCallback(() => {
  // Validação: palavra incompleta
  if (current.length < WORD_LENGTH) {
    showMessage("Palavra muito curta!");
    return;
  }

  const newGuesses = [...guesses, current];
  setGuesses(newGuesses);
  setCurrent("");

  // Verificar vitória
  if (current === secret) {
    showMessage("Incrível! 🎉");
    setGameOver(true);
    return;
  }

  // Verificar derrota
  if (newGuesses.length >= MAX_GUESSES) {
    showMessage(`Era: ${secret}`, 4000);
    setGameOver(true);
  }
}, [current, guesses, secret]);

Mensagem toast

const [message, setMessage] = useState("");

const showMessage = (msg, duration = 1800) => {
  setMessage(msg);
  setTimeout(() => setMessage(""), duration);
};

// No JSX — aparece e desaparece suavemente:
<div style={{
  opacity: message ? 1 : 0,
  transform: message ? "translateY(0)" : "translateY(-10px)",
  transition: "all 0.2s"
}}>
  {message}
</div>
